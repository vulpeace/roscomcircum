# Обход блокировок и белых списков с использованием Clash/Mihomo

===

### Перед началом прочтения – у вас должна быть ссылка на удаленный конфиг (подписку) для Clash. Обычно такой вариант подразумевает минимальную необходимость донастройки для конечного пользователя.

===

### Для Android
скачиваем последнюю версию клиента Clash Meta for Android с припиской arm64-v8a-release – [github.com](https://github.com/MetaCubeX/ClashMetaForAndroid/releases/latest).

Открываем приложение и разрешаем ему уведомления – без них система не даст приложению работать в фоне. Можно выключить для него все категории уведомлений, кроме "Статус Clash".

Переходим в Настройки -> Сеть, отключаем Системный прокси, в Режиме контроля доступа выбираем Разрешить выбранные приложения, а в Приложениях с контролируемым доступом выбираем все те, которые хотим пропускать через VPN.

Возвращаемся на главную страницу. Профиль -> значок + (Создать профиль) -> URL. Вводим имя профиля (любое понятное вам), в URL вставляем ссылку на вашу подписку, в авто обновлениях можно ввести желаемый период (обычно 60 минут). Сохраняем. Выбираем созданный профиль на странице профилей.

Возвращаемся на главную. Переходим в Прокси. Нажатие на кнопку со значком молнии должно запустить проверку задержки до всех прокси-серверов в подписке. Это займет некоторое время, особенно, если серверов много. Пробуем разные сервера (само собой, отдаем предпочтение имеющим задержку ниже).

Выбрав желаемый сервер, возвращаемся на главную и запускаем прокси. Разрешаем создание VPN-туннеля.


### Для ПК
отсутствует официальный клиент от разработчика Mihomo, однако существует неплохой клиент FlClashX.

Скачиваем последнюю версию клиента FlClashX с припиской windows-amd64-setup и устанавливаем его – [github.com](https://github.com/pluralplay/FlClashX/releases/latest). Запоминаем папку, куда он установился – в свойствах FlClashX.exe в настройках совместимости стоит включить запуск от имени администратора, иначе туннель работать не будет.

Нажимаем Добавить профиль и вводим ссылку на подписку. Режим оставляем По правилам. Во вкладке Настройки пролистываем вниз, в Настройках приложения включаем Переопределение, Автозапуск приложения, Скрытый запуск, Автозапуск прокси, Автопроверка обновлений.

Во вкладке Прокси нажимаем на стрелочку вниз у имеющейся группы прокси. Аналогично варианту на Android выбираем желаемый сервер. Во вкладке Профили можно отредактировать название и период обновления импортированной подписки.

На главной странице запускаем прокси.
